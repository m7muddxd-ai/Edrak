# إدراك — Android wrapper

الطريقة 1 (Android Studio): File > Open > اختار فولدر المشروع > استنى Sync > Build > Build APK(s).
الناتج: app/build/outputs/apk/debug/app-debug.apk

الطريقة 2 (من غير تنصيب حاجة): ارفع المشروع على GitHub، وادخل Actions > Build APK > Run workflow،
وبعد ما يخلص نزّل الـ APK من Artifacts.

الصفحة نفسها في app/src/main/assets/index.html
